# md-page-harvester

Micronaut modular monolith for downloading `.md` pages from a single source project.

The current state is intentionally a foundation: the application has an entry point, module boundaries, a Docker build, and a Portainer stack. Downloading, storage, and scheduling logic will be expanded over time.

## Structure

```text
apps/service              Micronaut runtime and application composition
modules/cqrs              shared CQRS contracts, command bus, and query bus
modules/api               HTTP boundary and future DTOs/controllers
modules/catalog           source project model and Markdown page metadata
modules/downloader        boundary for downloading Markdown files
modules/storage           boundary for persisting downloaded pages
modules/scheduler         orchestration and future jobs
deploy/portainer          Portainer stack
docs                      architecture and operations notes
```

## Local Docker Run

```bash
docker compose up --build
```

The application runs on Java 26 and listens on port `8080`. The health endpoint is available at `/health`.

## Portainer

Use `deploy/portainer/stack.yml`. The stack expects the `md-page-harvester:latest` image by default. Set `IMAGE_NAME` when using an image from a registry.

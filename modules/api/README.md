# api

Application HTTP boundary.

It currently contains a basic endpoint for downloading a remote Markdown page as a `.md` file:

```http
POST /api/pages/download
Content-Type: application/json
Accept: text/markdown
```

```json
{
  "uri": "https://example.com/docs/api-guide.md",
  "title": "Api Guide",
  "fileName": "api-guide.md"
}
```

The response is `text/markdown` with the `Content-Disposition: attachment` header. The controller only handles HTTP mapping and query creation; the actual download and output file naming are handled by `modules/downloader` through the shared `QueryBus`.

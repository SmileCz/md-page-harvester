# Portainer

The stack definition is in `deploy/portainer/stack.yml`.

## Expected Procedure

1. Build the Docker image:

   ```bash
   docker build -t md-page-harvester:latest .
   ```

2. Push the image to a registry if Portainer runs on another host.

3. Create a stack in Portainer from `deploy/portainer/stack.yml`.

4. Set the variables:

   ```text
   IMAGE_NAME=md-page-harvester:latest
   HOST_PORT=8080
   SOURCE_PROJECT_URI=
   SOURCE_PROJECT_BRANCH=main
   ```
